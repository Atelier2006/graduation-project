# 詐欺シミュ HTML版

サーバーを動かさずに使える版です。**`index.html` をダブルクリックすると、ブラウザで開きます**（Edge・Chrome・Safari・Firefox）。インターネットも要りません。

| できること | |
| --- | --- |
| 体験 | 3本のシナリオ（フィッシング・偽通販・サポート詐欺）を、仮想スマホと仮想パソコンで体験し、結果と解説を見る |
| 力だめしテスト | 体験の前と後に同じ10問を解いて比べる |
| アンケート | 5段階の4問と感想 |
| みんなの結果 | このブラウザで体験した人の結果（展示会で1台のパソコンをみんなで使うと、その台のみんなの結果になる） |
| 自分の記録 | 体験とテストの記録。「記録をすべて消す」で次の人に交代できる |

- 記録は、そのブラウザの中（localStorage）だけに残ります。どこにも送りません。
- 会員登録・ログイン・ランキングは、Django 版（このリポジトリのいちばん上のフォルダ）だけにあります。
- スマホで開くとき：このフォルダで `python -m http.server 8000` を実行し、同じ Wi-Fi のスマホで `http://（パソコンのIPアドレス）:8000/` を開きます。

## 直すとき

`js/app.js`（HTML版の画面）と `index.html` は、このフォルダで直します。
それ以外（仮想環境・シナリオ・CSS・写真・テストの問題）は Django 版がもとなので、Django 版を直してから、いちばん上のフォルダで `python tools/build_html.py` を実行してうつします。
確かめるときは `node e2e/html.js` です。
