# 3. テンプレートの選定

> 制作開始前の検討資料｜版 0.2（2026年11月13日）｜チームF「詐欺シミュ」
> 調べたもの：[Template Party の完成テンプレート一覧](https://template-party.com/db_new/list/?category=template)（2026年11月13日時点で1,025点）、同サイトの[利用規約](https://template-party.com/read.html)と[よく頂く質問](https://template-party.com/faq.html)

Webサイトは1から作らず、Template Party のテンプレートを土台にする。ここではテンプレートを選び、Django と Bootstrap に組み込めるかを確かめた。テンプレートは**Googleドライブに保存**し、GitHub には入れない（3.5節）。**組み込みは、まだ行わない。**

---

## 3.1 選ぶときの条件

| # | 条件 | 理由 |
| --- | --- | --- |
| 1 | 文字が大きく、ボタンが押しやすい | ターゲットに高齢者とネットに疎い人がいる（スライド4・11） |
| 2 | スマホでも崩れない | 概要説明の必須条件（レスポンシブデザイン） |
| 3 | メニューが少なく、アプリの画面に向いた作り | 画面は15ほど。お店や会社の紹介用の大きな写真・長いページは使わない |
| 4 | 落ち着いた配色で、スライドの色（青・黄色）に近い | 発表資料と見た目をそろえる。防犯の作品なので派手すぎない |
| 5 | Bootstrap と一緒に使える | 概要説明の必須条件（CSSフレームワーク） |
| 6 | 新しく、規約が分かりやすい | 不具合や古い書き方が少ない |

## 3.3 おすすめ：tp_universal1（色は clinic）

| 項目 | 内容 |
| --- | --- |
| 名前 | アクセシビリティに配慮した（WCAG 2.2 AA目安）無料ホームページテンプレート **tp_universal1** |
| 色 | **clinic**（紺＋オレンジ）。スライドの青と黄色の矢印に近い。ほかに jichikai（緑）、office（ワイン）、giin（紺＋緑）、kaigo（茶＋ピンク）がある |
| プレビュー | https://template-party.com/template/tp_universal1/tp_universal1_clinic/ |
| ダウンロード | https://template-party.com/db_new/detail?category=template&id=1478 |
| 中身（jichikai で確認） | HTML 5ページと説明書（_readme.html）、CSS 4つ（style・theme・form・inview）、jQuery 3.6.0 と main.js。フォントは Google Fonts（Noto Sans JP）、アイコンは Font Awesome 6.5.2（どちらもCDNから読み込む） |

**おすすめする理由**

1. **高齢者・ネットに疎い人に向けて作られている。** 文字は標準で16〜18px、「標準／大」の文字サイズ切替ボタンがある。文字と背景の色の差（コントラスト）は4.5：1以上。
2. **メニューが隠れない。** ハンバーガーメニューやドロップダウンがなく、スマホでもメニューのボタンが並ぶ。迷いにくい。
3. **キーボードだけでも操作できる。** 「本文へスキップ」やフォーカスの枠が入っている。
4. **色を1つのファイルで変えられる。** theme.css の変数（`--primary-color` など）を変えるだけで、全体の色が変わる。
5. **新しい**（2026年10月29日公開）。

**気になる点と対応**

| 気になる点 | 対応 |
| --- | --- |
| 自治会・クリニックなどの紹介サイト向けで、写真や電話番号の欄がある | 写真は使わず、ヘッダーの電話番号の欄は「ログイン」「マイページ」のボタンに置き換える |
| メニューは5つまでがきれいに収まる | 2章 2.3節のとおり、メニューを5つにする |
| フォントとアイコンをインターネットから読み込む | 展示会でネットにつながらない場合に備え、フォントと Font Awesome のファイルもドライブに置き、各自の static に置く |

## 3.4 どの画面に使うか

| 画面 | 使う見た目 |
| --- | --- |
| ホーム、ログイン、新規登録、モード選択、開始画面、見抜けた、解説、テスト、テストの結果、アンケート、マイページ、みんなの結果、相談先 | **テンプレート**のヘッダー・メニュー・フッター。中の部品（カード、フォーム、グラフの枠など）は Bootstrap |
| 仮想環境（仮想パソコン・仮想スマホと、その中の偽のSMS・偽のログイン画面・偽の通販サイト・警告画面・電話） | **テンプレートを使わない。** Bootstrap と自作のCSSで、本物そっくりに作る（[4章](04-virtual-env.md)）。アプリの画面と仮想環境の見た目を分けることで、「ここからが練習の場面」だと分かる |
| 被害の「その後」 | 仮想環境の中で起きたあと（カード会社の通知など）、テンプレートの画面でまとめて説明する |
| 管理画面 | Django 標準の管理サイト（見た目は変えない） |

偽の通販サイトは、Template Party のショップ向けテンプレート（例：tp_shop11）を土台にすることもできる。規約では、複数のテンプレートを組み合わせて1つのサイトを作ってよい（3.5節）。ただし、ショップのページの下にも著作表示が入る。

## 3.5 規約と置き場所

**利用規約の要点**（2026年11月13日に確認）

| 内容 | 規約 |
| --- | --- |
| HTML・CSSの改造 | **自由**。WordPress などに組み込んで使ってもよい |
| 一番下の著作表示「Web Design:Template-Party」 | **消さない。見えなくする加工もしない。** 外したい場合は有料のライセンス契約が必要 |
| 複数のテンプレートの組み合わせ | **よい**（よく頂く質問） |
| テンプレートとしての再配布 | **禁止** |
| テンプレート・パーツを不特定多数に向けて公開すること | **禁止**（特別な契約をした場合を除く） |
| 法律・公序良俗に反するサイトでの利用 | 禁止。詐欺シミュは防犯の学習が目的で、偽の画面もすべて架空なので当たらないと考える |
| 同梱の画像 | 「すかし」の入った画像は外部の著作物で、同梱されていない。同梱の写真は使えるが、詐欺シミュには合わないので使わない |

**置き場所：Googleドライブ（11/13 決定）**

チームの GitHub リポジトリは**公開（public）**なので、テンプレートのファイル一式を置くと「再配布」に当たるおそれがある。そのため、次のように分ける。

| 置く場所 | 置くもの |
| --- | --- |
| **Googleドライブ** | ダウンロードしたテンプレートの zip と、展開したファイル（css・js・images など）。**手を加えずに**そのまま置く。共有はメンバーと担当教員だけにする（「リンクを知っている全員」にしない） |
| GitHub | 自分たちで書いたものだけ：Django のテンプレート（`base.html` など）、自作のCSS（色の上書き・Bootstrap との調整）、`.gitignore` |
| 各自のパソコン | ドライブからテンプレートのファイルを取ってきて、決まった場所（例：`static/vendor/tp_universal1/`）に置く。この場所は `.gitignore` に入れて、コミットされないようにする |

- 新しいメンバーのパソコンや展示会のパソコンでも動かせるように、README に「ドライブのどのフォルダから、どこに置くか」を書く。
- 自動テスト（CI）はテンプレートのファイルがなくても通るようにする（見た目のファイルがなくても、画面の中身は確かめられる）。

## 3.6 Bootstrap と一緒に使えるか

テンプレート（tp_universal1_jichikai）のCSSと、Bootstrap 5.3.3 のCSSに出てくるクラス名を比べた。

| | クラスの数 |
| --- | --- |
| テンプレートのCSS（style・theme・form・inview） | 112 |
| Bootstrap 5.3.3 | 2,025 |
| **両方で使われている名前** | **4つ**：`btn`、`form-label`、`lead`、`small` |

ぶつかる名前は少ないので、一緒に使える。テンプレートのファイルはドライブのものを**そのまま使い、書き換えない**。調整はすべて自作のCSSで行う。

1. **読み込む順番**を、Bootstrap → テンプレート → 自作のCSS にする（あとに読んだ方が優先される）。
2. ぶつかる4つのうち、`btn` に気をつける。テンプレートの `.btn` は `<p class="btn"><a>…</a></p>` の形で中の `<a>` を飾る。この形を使うと、Bootstrap の `.btn` の余白や枠が外側の `<p>` にもかかる。**ボタンは Bootstrap の書き方（`<a class="btn btn-primary">`）にそろえ、テンプレートの書き方は使わない。**
3. 色は、自作のCSSでテンプレートの変数（`--primary-color` など）を上書きして変える。
4. 自作のクラスには決まった頭文字を付ける（計画書の命名規則では `mk-`。作品名に合わせて `ss-` などにするか決める）。
5. Bootstrap は文字の大きさや余白の初期値を変える（Reboot）。組み込んだあとに、文字サイズ切替とフォーカスの枠が効いているかを確かめる。

## 3.7 組み込みの方針（実装のときに行う）

1. テンプレート（tp_universal1_clinic）をダウンロードし、Googleドライブに保存する。
2. 各自がドライブから `static/vendor/tp_universal1/` に置く（`.gitignore` 済み）。
3. 共通の部分（ヘッダー・メニュー・フッター）を Django の `base.html` にし、各画面は `{% extends "base.html" %}` で中身だけを書く。
4. フォントと Font Awesome は、展示会でネットにつながらなくても表示できるように、テンプレートと同じくドライブから置く。
5. フッターの「Web Design:Template-Party」は残す。
