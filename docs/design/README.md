ブラウザの中の仮想環境で、3本のシナリオを最後まで体験できる試作品を作った：[prototype/](../../prototype/README.md)（`prototype/index.html` をブラウザで開く）。ログイン・テスト・みんなの結果は、本番の Django で作る。
