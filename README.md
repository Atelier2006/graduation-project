## 必須機能

データベースを使い、次の機能を組み込みます。

- [ ] **保存**：お気に入り・履歴・マイページ
- [ ] **共有**：ランキング・レビュー・コメント
- [ ] **分析**：統計・トレンドの可視化
- [ ] ログイン認証（パスワードはソルト付きでハッシュ化）
- [ ] スマホ対応のレスポンシブデザイン
