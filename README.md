# graduation-project

2026年度 後期 卒業制作Ⅱ のチーム開発リポジトリです。

> テーマは「ネット詐欺見抜きトレーニング」に決定しました（作品名は仮称）。詳しくは [要件定義書](docs/requirements.md) を見てください。メンバーと担当は決まり次第、下の表を埋めてください。

## プロジェクト概要

| 項目 | 内容 |
| --- | --- |
| 作品名 | ミヌケル（仮称）：ネット詐欺見抜きトレーニング |
| 一言でいうと | 架空のメール・SMS・SNS・Webサイトを見て「本物か詐欺か」「どう行動するか」を答え、詐欺を見抜く力と「迷ったら公式から確かめる」習慣を身につける学習サービス |
| 第1階層：ユーザー価値 | 安全（＋学べる・楽しい） |
| 第2階層：技術要素 | データ分析・データの可視化（＋WebAPI開発） |
| 第3階層：対象分野 | 地域社会（＋学生生活） |
| 想定ユーザー | スマホを使う一般の方（学生・社会人と、その家族） |

## 技術スタック

制作物の条件（[概要説明](docs/overview.md#制作物の条件)）に沿って決定します。

| 区分 | 採用技術 | 条件 |
| --- | --- | --- |
| サーバーサイド | Python 3.12／3.13 ＋ Django 5.2 LTS | Windows上で動作する PHP / Java / Python のフレームワーク |
| データベース | SQLite（テーブル21個の予定） | テーブル3つ以上 |
| CSSフレームワーク | Bootstrap 5.3 | Bootstrap / Tailwind CSS のどちらか |
| 外部API | 使わない（ネットなしでも動かすため） | 使う場合は1つに絞る |

## 必須機能

データベースを使い、次の機能を組み込みます。

- [ ] **保存**：お気に入り・履歴・マイページ
- [ ] **共有**：ランキング・レビュー・コメント
- [ ] **分析**：統計・トレンドの可視化
- [ ] ログイン認証（パスワードはソルト付きでハッシュ化）
- [ ] スマホ対応のレスポンシブデザイン
