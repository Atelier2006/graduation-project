## Refero の実例を画面に反映した箇所

教材全体の区切り線と操作部品の角には Common、レシピ記事の生成りの紙色と濃い本文には Eat Real Food、商品検索の丸い入力欄には Shop、配送案内の落ち着いた灰緑の背景には Custo を参考にした。各スタイルへのリンクは下表に記載している。仮想端末の寸法や警告・通知の発生条件はシナリオに合わせている。

**Refero Styles にないもの**

| 場面 | 作り方 |
| --- | --- |
| 仮想スマホ（状態バー、ロック画面、通知、ホーム画面とドック、メッセージ、ブラウザ、電話、キーパッド） | ふつうのスマホの作りに合わせた（日付の下に大きな時刻、半透明の通知、下にあるアドレスバー、丸いキーパッド など）。メーカーのロゴは使わない |
| 仮想パソコンのブラウザ（タブ、アドレスバー、ブックマーク、右上の最小化・最大化・閉じる） | ふつうのブラウザの作りに合わせた。全画面のときの「Esc キーを長押し」の案内も、実際のブラウザと同じ出し方 |
| 偽の警告画面（サポート詐欺） | 実際の詐欺の画面によくある作りにした（青い全画面、パソコンの部品をまねた窓、大きな電話番号、偽のスキャン、ブラウザの「〜の内容」の小窓） |
| 家族とのチャット（トモトモ） | 架空のメッセージアプリ。よくあるチャットの作り（相手の名前と丸いアイコン、吹き出し、既読） |

## 「AIが作った感じ」を出さないための決まりごと

1. **絵文字をアイコンに使わない**。線の絵のアイコン（SVG）にする（鍵・カート・電話・警告の三角 など）。
2. **写真の代わりの文字や絵を置かない**。写真ごとに出典と利用条件を記載する（[img/CREDITS.md](img/CREDITS.md)）。
3. **ふつうのサイトにあるものを置く**。パンくずリスト、ページ番号と更新日、ナビ、フッターのリンク、広告の枠の「広告・i・×」、使わないアプリのアイコン など。
4. **1つのサイトの中では、色・角の丸み・線の太さを、参考スタイルの数値にそろえる**。色を増やさない。
5. **偽のサイトは、本物と同じくらいきれいに作る**。「見た目があやしいから気づく」のではなく、アドレス・会社の情報・振込先・電話番号などで見抜く練習にする。
